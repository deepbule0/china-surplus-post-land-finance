## Main argument / 核心观点

China should pursue stronger household purchasing power and a sustainable local fiscal system together. Predictable public-service funding, better tax-sharing incentives, and responsible debt restructuring can support domestic demand while preserving manufacturing competitiveness.

中国应同步提高居民购买力、建设可持续的地方财政体系。稳定的公共服务资金、合理的税收分享机制和负责任的债务重组，有助于扩大内需并保持制造业竞争力。
