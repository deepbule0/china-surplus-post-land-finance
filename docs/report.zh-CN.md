# 中国贸易顺差与土地财政转型

[English](report.en.md) · [项目说明](../README.md)

*2026年10月13日。分析视角：中国的长期经济利益。政策建议属于分析判断；已公布的政策方向另行标明。*

## 1. 核心结论

中国的大规模对外顺差、居民需求偏弱，以及地方财政对土地收入依赖的下降，彼此存在联系。可持续的调整应当同时推进**居民购买力提升与公共服务资金保障**。

目标应是可持续的对外收支、强大的制造业与更高的居民福利。财政改革和即时的居民支持可以同步进行，无须等到税制全面重构完成后才提供帮助。

## 2. 数据究竟意味着什么

| 指标 | 数据 | 含义 |
| --- | --- | --- |
| 2025年海关口径货物贸易顺差 | 约**1.189万亿美元** [1] | 年度流量，不是政府利润，也不等于外汇储备增加额。 |
| 2025年经常账户顺差 | **7350亿美元** [2] | 包括服务与收入收支；海关和国际收支的货物统计口径也有差异。 |
| 2021年地方国有土地使用权出让收入 | **8.705万亿元人民币** [3] | 政府性基金预算中的收入总额。 |
| 2025年同口径收入 | **4.152万亿元人民币** [4] | 根据决算数据计算，比2021年约减少**52.3%**。 |
| 2025年地方一般公共预算本级收入 | **12.208万亿元人民币** [5] | 不含中央转移支付。 |
| 2025年地方一般公共预算支出 | **24.436万亿元人民币**，约占全国支出的**85%** [5] | 大量公共支出由地方实施。 |
| 2025年中央一般公共预算对地方转移支付 | **10.193万亿元人民币** [5] | 转移支付已经承担地方支出的重要资金来源。 |

土地收入属于**政府性基金预算**，与一般公共预算分列。其中也需支付征地、补偿和土地开发等成本。因此，土地收入总额下降，并不等于可自由支配财力等额减少，也不能直接与一般公共预算的收支差额相加。

相关的会计恒等式是：

$$\text{经常账户余额} = \text{国民储蓄} - \text{国内投资}。$$

它说明顺差对应的国内储蓄—投资关系，不能单凭这一公式确定顺差成因。对外金融资产由企业、银行、投资者和货币当局等持有，并非全部是美元资产或官方储备。汇兑损益取决于计价币种和套期保值；总回报还受投资收益、资产价格与购买力影响。

适度顺差可以支持未来进口和老龄化社会的需要。但过大的顺差可能加深对外国需求的依赖，并增加贸易摩擦风险。资产多元化能够管理投资风险，却不能直接修复国内需求不足。

## 3. 土地财政为何与顺差有关

我们的判断是，土地收入下降可能通过两条渠道强化经济失衡：

- **需求渠道：**压缩支出、拖欠工程款，以及公共服务保障的不确定性，可能削弱收入并提高居民预防性储蓄。
- **供给渠道：**地方为争取税源和就业，可能继续竞争工厂与工业项目，其中也可能包含商业回报较弱的项目。

居民消费偏弱而生产继续扩大，可能提高经济对出口的依赖。这是一种有合理依据的传导机制，并非对全部顺差成因的定量解释。生产率、海外需求、供应链和汇率同样重要；财政紧张也可能限制工业投资。

深层财政问题在于：使支出责任获得稳定财力支持，并改善地方支持居民与服务业的激励。转移支付本来就是财政体系的正常组成部分，因此地方本级收入与支出的差额，本身并不能证明地方政府资不抵债。

## 4. 历史经验

| 历史阶段 | 对中国的启示 |
| --- | --- |
| 全球金融危机前的中国 | 高投资可以与更高储蓄、大规模顺差同时存在；扩大投资本身不保证实现再平衡。[6] |
| 全球金融危机后的中国 | 国内投资和进口增加，连同海外需求减弱等变化，帮助缩小了顺差。投资质量和融资方式十分关键。[7] |
| 1985年《广场协议》后的日本 | 汇率升值、长期宽松、信贷激励与资产预期相互作用；不能把泡沫单独归因于升值。[8] |

政策上应避免仅依靠新一轮房地产与基建扩张，或一次剧烈的汇率调整来解决问题。

## 5. 可行的政策组合

1. **保障公共服务，清理拖欠款。**提高转移支付的可预期性，优先保障基本公共服务，偿付经核实的逾期款项。债务重组应与约束新增预算外举债同步推进。

2. **提高居民收入与保障水平。**完善基本养老金、医疗、失业保障、托育以及农业转移人口的公共服务可及性。可信的资金保障有助于降低居民为未来紧急支出储蓄的需要。

3. **重建地方收入激励。**推进适当的消费税改革，审视共享税分配与按支出需求安排的转移支付。中国的消费税针对特定商品，并不是覆盖全部零售消费的一般销售税；征收环节后移也不自动意味着收入按消费发生地分配。

4. **使事权与财力匹配。**考虑由中央或省级更多承担全国基本公共服务标准的资金保障，同时明确责任、发挥有效的地方执行能力。

5. **审慎安排新增税收。**经常性的房地产持有环节税，长期可能形成稳定的地方税源。但在房地产调整期间，应审慎设计估值、减免、居民现金流保护和延期缴纳机制。避免主要依靠向普通居民普遍加税或收费来弥补土地收入。本报告不预测出台日期。

6. **渐进调整对外收支。**扩大有经济价值的进口和国内服务业，保持汇率弹性，并按照回报、风险和流动性评估境外投资。对外投资改变顺差对应的融资或资产配置，**并不直接减少经常账户顺差**。人民币结算可以改变汇率风险，却不能消除储蓄—投资失衡。

居民支出增加也不会使顺差等额减少：国内产出、进口、投资和储蓄都会作出反应。适当的顺差规模取决于这些结果，本报告不设定缺乏依据的固定美元目标。

## 6. 已公布方向与分析建议的区别

| 措施 | 状态 |
| --- | --- |
| 拓展地方税源、完善转移支付、消费税征收环节后移并稳步下划地方、提高中央财政支出责任 | **2024年二十届三中全会《决定》**提出的方向；公布方向不代表实施已经全部完成。[9] |
| 地方隐性债务置换框架 | **6万亿元**新增地方债务限额，加上通过五年专项债安排提供的**4万亿元**资源。这是跨年度化债措施，不是新增10万亿元居民消费刺激。[10] |
| 中央承担大量地方债务 | 本文讨论的进一步改革可能性。已有置换通常发行正式的**地方政府债券**，并不自动把债务变成中央政府债务。[10] |
| 按消费地分配增值税收入、审慎分阶段推进经常性房地产持有环节税 | 本报告的分析建议，并非声称全国改革已实施完成。 |

债务置换可以缓解还本付息压力，但无法永久解决支出责任与可持续收入之间反复出现的错配。

## 7. 应观察哪些信号

重点观察税收分配细则落地、转移支付稳定性、民生资金可靠性、拖欠款清理，以及新增隐性债务约束。评估成效应看居民实际收入、消费、公共服务可靠性和经常账户，而不只是赤字率或债务额度。

2026年末的政策会议和2027年全国人大预算审议过程是值得关注的节点。本报告不宣称未来会议的确定日期，也不保证某一改革组合必然出台。
